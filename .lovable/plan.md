

## DIP - Website Header

### What we'll build:
A clean, professional header/navbar for the "DIP" project with:

1. **Left side** – "DIP" logo/brand name displayed prominently
2. **Right side** – Contact details (phone number, email, or similar contact info)
3. **Responsive** – Looks good on both desktop and mobile
4. **Homepage** – Updated landing page with the new header

### Design approach:
- Clean, minimal header with a subtle bottom border
- Bold "DIP" branding on the left
- Contact info (phone icon + number, email icon + email) aligned to the right
- Sticky header so it stays visible while scrolling
